# 🌐 Ipycharmer — Personal Portfolio

> **Live site:** `https://ipycharmer.github.io`

A fast, fully responsive personal portfolio built with pure HTML & CSS — no frameworks, no dependencies, no build step. Scores 90+ on Google PageSpeed Insights.

---

## ✨ Features

- **Animated hero section** with scroll-reveal on every section
- **Custom cursor** — dot + lagging ring that reacts to hover
- **Scrolling tech-stack ticker** — infinite loop of skills
- **6 skill cards**, **3 project showcases**, **experience timeline**
- **SVG favicon** — circular "A" in site blue, no external URL needed
- **SEO optimised** — meta description, keywords, Open Graph tags
- **Fully responsive** — works on mobile, tablet, desktop
- **Zero dependencies** — one `.html` file, that's it

---

## 🗂️ File Structure

```
ipycharmer.github.io/

```

That's it. One file. No node_modules, no build process, no config.

---

## 🚀 Deployment (GitHub Pages)

1. Create a repo named exactly **`YOUR_USERNAME.github.io`**
2. Upload `index.html` to the root
3. Go to **Settings → Pages → Deploy from branch → `main` → `/ (root)`**
4. Your site is live at `https://YOUR_USERNAME.github.io`

Any time you push a change to `main`, the site updates automatically within ~30 seconds.

## 🎨 Design Tokens

| Token | Value | Used for |
|---|---|---|
| `--accent` | `#4fc3f7` | Blue highlights, links, cursor |
| `--accent2` | `#43e8a0` | Green tags, pass states |
| `--accent3` | `#ff8a65` | Orange code highlights |
| `--bg` | `#080c10` | Page background |
| `--text` | `#e8edf2` | Primary text |

To change the colour scheme, just update these 5 variables at the top of the `<style>` block.
